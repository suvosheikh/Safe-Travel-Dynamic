# 🛡️ Safe Journey (Safe Travel)

**Safe Journey** is a high-security mobile application designed to ensure the safety of travelers through real-time tracking, emergency response systems, and localized safety information. Built with a "Cybernetic-Futuristic" aesthetic, it combines luxury design with critical safety infrastructure.

---
Data: 17 July 2026
## 🚀 Key Features

### 🆘 Emergency SOS Response
- **Panic Button**: Trigger immediate alerts to your pre-enlisted guardians and authorities.
- **SOS Logs**: Keeps a secure record of all safety incidents.

### 📍 Intelligent Trip Tracking
- **Real-time Monitoring**: Track your transport mode, route, and safety status.
- **Deviation Alerts**: Automatic detection of route deviations or unexpected stops.
- **Vehicle verification**: Manually log vehicle plate numbers and descriptions for added security.

### 📰 Safety Intelligence Dashboard
- **Live Safety News**: Stay updated with traffic alerts, emergency reports, and weather warnings.
- **Weather Insights**: Detailed hourly and daily forecasts tailored for travelers.

### 👮 Thana & Emergency Explorer
- **Station Finder**: Locate the nearest police stations (Thanas) in Bangladesh.
- **One-Tap Contact**: Direct dial and navigation to emergency services.
- **Comprehensive Database**: Includes police and fire service stations.

### 👨‍👩‍👧‍👦 Security Network (Guardians)
- **Trusted Circle**: Enlist guardians who receive live updates on your travel status.
- **Check-ins**: Automated check-in requests to ensure you are safe during journeys.

### 🏥 Medical & Personal Profile
- **Life-Saving Data**: Securely store blood group, allergies, chronic conditions, and special needs.
- **Security Score**: A gamified safety score that encourages users to complete their security protocols.

## 🎨 Design Philosophy
Safe Journey utilizes a unique **Cybernetic-Futuristic** visual identity:
- **Primary Canvas**: Slate 900/950 (Dark, professional tones).
- **Accents**: Emerald 400 (Success/Safety) and Coral/Red (Emergency/Alerts).
- **Glassmorphism**: Elegant card layouts with subtle borders and blurring effects.

---

## 🛠️ Technical Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose (Modern declarative UI)
- **Backend**: Supabase (Real-time DB, Auth, and Storage)
- **Architecture**: MVVM (Model-View-ViewModel)
- **API**: Gemini AI Integration (for safety insights and assistance)

## ⚙️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/suvosheikh/safe-travel.git
   ```
2. **Open in Android Studio**:
   Select **File > Open** and choose the project directory.
3. **Environment Configuration**:
   - Create a `.env` file in the root directory.
   - Set up your `SUPABASE_URL` and `SUPABASE_KEY`.
4. **Sync Gradle**:
   Wait for the project to sync and download dependencies.
5. **Run**:
   Deploy to a physical device or emulator.
